# LIFEOS

LIFEOS is a personal operating system for managing daily life with structure and measurable progress.

## Core Areas

- Daily planning and time blocking
- TOPIK preparation
- Korean vocabulary and spaced repetition
- Grammar, reading, listening and writing practice
- Habits and discipline
- Goals and milestones
- Income and expenses
- Budgets and savings
- AI-assisted planning and review

## Product Principle

LIFEOS connects:

`TIME → TASKS → STUDY → HABITS → GOALS → MONEY → DISCIPLINE`

The system should reduce the need for manual planning while keeping important decisions under user control.
